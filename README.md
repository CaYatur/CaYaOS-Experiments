2024–2025 · CaYaBasicOS'a giden yol: Cosmos (C#) çekirdekleri, önyükleyici ve x86 assembly denemeleri.

[CaYaBasicOS](https://github.com/CaYatur/CaYaBasicOS)'a giden yolda yaptığım işletim sistemi denemeleri:

| Klasör | İçerik |
|---|---|

| `CosmosTest/`, `CosmosKernel1/`, `CosmosKernel2/`, `CaYaTestOSP/` | Cosmos (C#) ile ilk çekirdek denemeleri |
| `CaYaOS/` | Cosmos tabanlı komut satırlı işletim sistemi (~1.000 satır) |

| `CaYaRecovery/` | Sıfırdan x86 assembly ile yazılmış önyükleyici, çekirdek ve önyükleme menüsü (Kasım 2025) |
