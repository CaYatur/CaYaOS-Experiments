🚀 BOOT AKIŞI
═══════════════════════════════════════════════════════════════════════════════

1. BIOS Power ON
   ↓
2. BIOS: MBR'ı 0x7C00'e yükle ve çalıştır
   ↓
3. boot.asm _start
   ├─ Stack/Segment setup
   ├─ Ekranı temizle (BIOS int 0x10)
   ├─ Boot menüsü göster:
   │  ├─ "=== CaYaDev Recovery v1.0.0 ==="
   │  ├─ "32/64-bit Compatible"
   │  └─ "Press ENTER"
   ├─ Enter tuşu bekle (BIOS int 0x16)
   ├─ GDT setup (3 descriptors)
   └─ Protected Mode'a geç (CR0.PE = 1)
   ↓
4. pm_entry (32-bit Protected Mode)
   ├─ Segment register'ları setup et
   └─ jmp 0x10000 (Kernel'e atla)
   ↓
5. kernel.asm kernel_start
   ├─ Ekranı temizle (Video buffer fill)
   ├─ Kernel başlığını yazdır
   ├─ Sistem bilgisi (32/64-bit compatible)
   └─ Sonsuz döngü (jmp $)

🎯 TEKNİK DETAYLARı
═══════════════════════════════════════════════════════════════════════════════

BOOT.ASM İçeriği:

  0x7C00-0x7C02:  jmp short _start       (Jump to bootloader code)
  0x7C03-0x7C52:  BPB (BIOS Parameter)   (BIOS compatibility)
  0x7C53-0x7D00:  Bootloader code        (~170 bytes)
  0x7D00-0x7D17:  GDT (Global Desc Tab)  (24 bytes)
  0x7D18-0x7D50:  Protected Mode entry   (~56 bytes)
  0x7D50-0x7D80:  String messages        (~48 bytes)
  0x7D80-0x7FFE:  Padding (zeros)        (~510 bytes total)
  0x7FFE-0x7FFF:  Boot signature         (0xAA55)

KERNEL.ASM İçeriği:

  0x10000+:       Kernel entry point
  0x10000-0x10050: Main kernel code
  0x10050-0x10100: GDT, IDT, Page tables
  0x10100-0x10200: Kernel string data
  0x10200+:       Available for future code

ISM 9660 Boot Yapısı:

  ├─ System Area (sectors 0-15)
  ├─ Primary Volume Descriptor
  ├─ El-Torito Boot Catalog
  ├─ Boot Image (boot.bin - 512 bytes)
  └─ Kernel data (kernel.bin - 16384 bytes)
